A collection of  10 simple implementations of classic cipher, hashing, and checksum algorithms built from scratch in Python—ranging from the historical Caesar Cipher to the modern SHA-256.
Purposes: This project is purely an educational exploration to understand the inner workings and mathematical principles behind popular encryption and hashing algorithms.

Disclaimer: These implementations are simplified for educational purposes and tested on basic test cases. They are not intended for production use or secure real-world applications.
Prerequisites & Requirements: Python 3.8 or higher. Dependencies: pytest, cryptography.
You can install it all through: pip install pytest cryptography
All algorithms include unit test coverage located in test_algorithms.py. You can run the entire test suite using pytest: pytest test_algorithms.py 
or simply in the folder typing: pytest -v
